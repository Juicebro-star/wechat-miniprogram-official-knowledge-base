    1. A 新增 API wx.createWorker 可创建多线程 Worker
    2. A 新增 API wx.getUpdateManager 提供小程序强制更新机制
    3. A 新增 API canvasContext.measureText 支持查看文本在当前canvas状态下的大小
    4. A 新增 API canvasContext.globalCompositeOperation 支持设置要在绘制新形状时应用的合成操作的类型
    5. A 新增 API canvasContext.arcTo 可根据控制点和半径绘制圆弧路径
    6. A 新增 API canvasContext.strokeText 提供绘制文本的方法
    7. A 新增 API canvasContext.lineDashOffset 可设置虚线偏移量
    8. A 新增 API canvasContext.createPattern 可对指定的图像创建模式
    9. A 新增 API canvasContext.shadowBlur/shadowColor/shadowOffsetX/shadowOffsetY 可设置阴影的相关样式
    10. A 新增 API canvasContext.font 可设置当前字体样式
    11. A 新增 API canvasContext.transform 可使用矩阵多次叠加当前变换
    12. A 新增 API canvasContext.setTransform 使用矩阵重新设置（覆盖）当前变换
    13. A 新增 API LivePusherContext.snapshot 可在推流中进行拍照
    14. A 新增 配置 window.backgroundColorTop window.backgroundColorBottom 可分别设置窗口顶部和底部的背景颜色
    15. U 更新 API wx.createInnerAudioContext 新增 volumn 属性，可调节音量
    16. U 更新 API wx.login wx.getUserInfo wx.getShareInfo wx.getWeRunData 新增 timeout 参数，可设置超时时间
    17. U 更新 API wx.getImageInfo 增加返回 orientation 和 type 值
    18. U 更新 组件 cover-view 支持设置 overflow: scroll 产生局部滚动区域
    19. U 更新 组件 cover-view 支持设置 position: fixed 使之相对窗口固定
    20. U 更新 组件 open-data 支持渲染 userInfo 相关信息
    21. U 更新 组件 movable-view 新增 bindchange 事件
    22. U 更新 组件 movable-view 支持缩放手势
    23. U 更新 组件 movable-view 新增 bindvtouchmove bindvtouchmove 事件
    24. U 更新 组件 movable-view 新增 disabled 属性以禁用滑动
    25. U 更新 组件 input textarea 新增 adjust-position 属性控制是否自动上推页面
    26. U 更新 组件 input textarea 在 bindfocus 事件回调里返回键盘高度
    27. U 更新 组件 picker 新增 bindcancel 事件
    28. U 更新 组件 新增 bindtouchforcechange 事件
    29. U 更新 自定义组件 样式前缀化支持类名传递
    30. F 修复 API wx.showModal 的 cancelText 和 confirmText 只能输入 4 个英文字符的问题
    31. F 修复 组件 live-player 无法停止播放的问题 反馈详情
    32. F 修复 组件 input 多个空格在失焦时只显示一个空格的问题 反馈详情
    33. F 修复 组件 input 在 disabled 状态下设置 color 无效的问题
    34. F 修复 组件 slider 设置 transform 导致滑块滑动异常的问题
    35. F 修复 组件 form 在安卓下键盘弹起时不触发 submit 事件的问题
    36. F 修复 框架 在安卓滚动时点击会触发 tap 事件的问题
    37. F 修复 框架 onReachBottom 事件在快速滑动出现触发次数异常的问题 反馈详情
    38. F 修复 框架 转换 rpx 单位无效的问题 反馈详情
