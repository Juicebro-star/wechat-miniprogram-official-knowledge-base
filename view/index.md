# 视图层 View

框架的视图层主要使用 WXML 与 WXSS 编写。

视图层可以将逻辑层的数据反映在页面上，同时将页面上的用户事件发送回逻辑层。

- WXML (WeiXin Markup language) 用于描述页面的结构。
- WXS (WeiXin Script) 是辅助 `WXML` 使用的简单脚本。
- WXSS (WeiXin Style Sheet) 用于描述页面的样式。
